# 聆心小开前端视觉优化设计说明

## 目标

在不改变现有业务功能与前后端交互的前提下，将登录页、Vue 首页、管理页和两套传统聊天页面统一为“林间静愈”视觉方向。界面应显得安静、温暖、可信且更成熟，避免通用模板式的紫色、过量毛玻璃、密集阴影和装饰性动效。

本轮不在产品界面中使用项目 Logo，也不新增插画、第三方 UI 库或字体依赖。

## 设计基线

- `DESIGN_VARIANCE: 5`：保留现有信息结构，对排版、布局比例、视觉层级和组件外观做中等幅度调整。
- `MOTION_INTENSITY: 3`：仅保留有状态意义的进入、悬停、聚焦与发送反馈；尊重 `prefers-reduced-motion`。
- `VISUAL_DENSITY: 4`：维持心理服务产品需要的舒缓留白，同时避免大面积空洞。
- 主题固定为浅色，使用森林绿作为唯一强调色。

## 品牌与视觉语言

### 色彩

- 页面底色采用暖白、雾绿和低饱和灰绿，避免冷白和高饱和色。
- 主文字使用深森林灰绿，正文与辅助文字保持清晰对比。
- 交互强调统一使用森林绿，不再保留 Vue 脚手架中的紫色变量。
- 陪伴页现有的粉红爱心强调将收敛为与全站一致的叶绿色图形语言，但不改变按钮含义或功能。

### 字体与排版

- 使用现有系统中文字体栈，不引入网络字体。
- 标题适度加重并收紧字距，正文保持舒展行高。
- 首页建立更明确的品牌标题、引导语和入口层级，不使用超大标题。
- 表单标签、辅助信息、聊天时间等采用一致的字号阶梯。

### 形状与质感

- 使用一套统一圆角尺度：小组件约 10px，中型控件约 14px，主要容器约 20px。
- 按钮以中等圆角矩形为主，只有图标按钮和状态点使用圆形。
- 减少全屏毛玻璃和多层高光，仅在悬浮层或必要的固定区域使用轻微模糊。
- 阴影改为低透明度、短距离的绿色中性色阴影，主要依靠边框、层级和留白区分内容。

## 页面设计

### 登录与注册页

- 保留左右分栏、Three.js 叶片、登录注册切换、字段顺序、提交逻辑和成功过渡。
- 降低叶片与背景的泛白感，提升表单可读性，让叶片成为安静的品牌氛围而不是视觉噪声。
- 登录卡改为更克制的实体浅色面板，优化标题、切换控件、输入框、错误提示和主按钮层级。
- 移动端继续使用上下布局，并保证表单在小屏和横屏下可完整滚动。

### Vue 首页

- 保留解惑助手、倾诉空间、管理员入口和退出操作，链接目标不变。
- 将当前窄列表调整为更有呼吸感的欢迎区域与双入口布局；两项服务可以有不同的图标细节，但共享同一视觉系统。
- 页面背景加入非常轻的叶脉或自然形状装饰，仅使用 CSS，不新增图片资源。
- 管理入口继续仅对管理员显示，视觉上降低权重。

### 管理页

- 保留单一导出功能，不扩展为仪表盘。
- 与首页统一页头、内容宽度、卡片质感、按钮与状态样式。
- 数据导出保持主操作清晰，同时通过说明层级表达其敏感性。

### 心理科普与心理陪伴页

- 保留现有侧边栏、会话历史、聊天消息、输入框、快捷问题、弹窗和所有 JavaScript 事件绑定。
- 两页共享同一基础视觉变量和组件外观，通过标题与图标保留各自语义。
- 侧边栏降低玻璃质感，导航选中态改为低饱和绿底与明确边框。
- 欢迎区域更轻、更像内容引导；消息气泡减少渐变和悬浮位移，强化长文本阅读体验。
- 输入区维持固定位置与当前发送行为，只调整边框、阴影、焦点态和移动端间距。
- 弹窗统一遮罩、容器、表单与按钮样式，不更改其打开、关闭和保存逻辑。

## 不变边界

以下内容不得因视觉优化发生变化：

- Vue Router 路径与路由守卫。
- API 地址、HTTP 方法、请求字段、Session、SSE 解析和错误处理。
- 登录注册字段名称、顺序、校验和提交行为。
- 聊天模式、历史记录、清空、导出、日记、情绪分析和冥想逻辑。
- 后端 Python 代码、数据库结构与配置。
- 用户可见功能数量和导航信息架构。

允许的结构调整仅限于增加不承载业务状态的视觉容器、装饰元素或辅助类名。现有 `id`、`data-*` 属性和 JavaScript 查询目标必须保留。

## 实施方式

- Vue 页面沿用现有单文件组件和原生 CSS，不增加依赖。
- 清理 `web/src/style.css` 中残留的 Vite 示例样式，建立全局视觉变量与基础可访问性规则。
- 传统页面优先通过共享视觉覆盖样式统一外观，避免复制更多业务脚本或重写页面。
- 最终重新生成 `templates/dist`，保持可直接部署的构建产物同步。

## 验收标准

- 桌面与移动端页面视觉一致，文字对比清晰，没有横向溢出或被遮挡的控件。
- 键盘焦点清楚，按钮、链接和输入框维持原有可操作性。
- `prefers-reduced-motion` 下关闭非必要动画和位移。
- 页面没有紫色默认主题、过量毛玻璃、过强阴影、无意义渐变或过多圆角胶囊。
- Vue TypeScript 检查和生产构建通过，后端测试保持通过。
- 浏览器冒烟测试确认登录注册切换、首页入口、聊天输入区域和管理导出按钮仍连接原有逻辑。
- 前后端开发服务启动后，登录页、首页、科普页、陪伴页和管理页均可访问或按权限正常跳转。
