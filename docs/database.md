# 数据库与隐私

SQLite 是唯一的持久化存储，默认位于 `templates/data/chat.db`。每一轮完成的陪伴对话在同一事务中写入：

| 表 | 内容 |
| --- | --- |
| `users` | 用户身份、密码哈希与管理员标记 |
| `chat_messages` | 完整用户/助手对话正文，按用户与会话隔离 |
| `assessment_snapshots` | 陪伴模式的展示安全状态快照 |
| `context_checkpoints` | Pi 上下文使用的心理支持摘要检查点 |

科普模式只写消息，不写状态快照或检查点。删除指定会话时，会同时删除其消息、快照和检查点。

## 快照与检查点

- 快照不是量表、诊断或正式风险评估。公开接口只允许六个展示字段，不返回内部风险等级或证据。
- 检查点只用于下一轮模型上下文构造。完整聊天记录保留，不会因压缩而删除。
- 管理员导出默认只包含用户和聊天正文，不包含状态快照或上下文摘要。

本地实验中的聊天正文仍可能是敏感信息。请只在受控设备上保存数据库、谨慎分发管理员导出，并在人工测试后按需要删除测试会话。
