# 用户使用说明

## 注册和登录

访问 `/login`，在“注册”页填写：

- 称呼：3–32 个可见字符，不能含空格，且不能与他人重复。
- 学号：1–32 个可见字符，一个学号只能注册一次。
- 密码：至少 8 位。

注册成功会自动登录。以后登录必须同时输入同一称呼、学号和密码。项目没有默认公共账号，也不会在页面保存明文密码。

常见提示：

- “该称呼已被使用”或“该学号已注册”：已有账户，不要重复注册。
- “称呼、学号或密码错误”：三项中至少一项与注册信息不一致。
- “无法连接服务”：后端没有启动或网络不可达，不代表账号不存在。
- “操作过于频繁”：触发安全限流，请稍后再试。

## 功能入口

- `/home`：首页和功能导航。
- `/info`：心理科普，用于了解非诊断性的心理学知识。
- `/companion`：心理陪伴，用于表达感受和获得一般支持。

登录状态保存在安全 Cookie 中；刷新页面仍可恢复。公共设备使用完后请退出登录。

## 聊天记录和情绪分析

聊天记录按会话保存在服务器 SQLite 数据库中，可用于刷新后的历史恢复。用户只能访问自己的记录，并可以删除自己的指定会话。

情绪分析返回六个粗略分数，仅用于当次界面展示，不是医学诊断，也不会单独保存分析结果。不要把它作为健康决策依据。
