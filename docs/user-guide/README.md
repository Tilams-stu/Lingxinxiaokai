# 使用说明

## 注册与登录

访问 `/login`，使用昵称、学号和至少 8 位密码注册。登录状态保存在安全 Cookie 中；公共设备使用后请退出登录。

## 两种聊天模式

- `/companion`：表达近况并获得非诊断性的陪伴支持。侧栏“状态回顾”仅整理当前会话中明确表达的信息；它不是心理量表、诊断或风险评估。
- `/info`：阅读/询问心理科普。助手使用本地审核资料卡时，回答底部会显示来源行。

聊天记录以会话保存，刷新后可恢复。用户可删除自己的指定会话；删除不可恢复。

### 状态回顾的准备进度

状态回顾需要当前会话中完成 8 次用户表达。每次用户消息成功得到回复并保存后计为 1 次；助手消息、其他会话和失败请求不计入。未达到 8 次时，页面会显示“还需要 n 条对话才可进行回顾”，不会展示带有 `unknown` 的状态字段。达到 8 次后，页面才展示情绪、关切、日常功能、保护因素、信息充分度和后续关注目标。

### 管理员入口

管理员没有单独的账号或登录页。部署者先从普通 `/login` 注册账号，再按[开发文档](../development.md#管理员账号与查询)在服务器终端执行 `set-admin <username>`。使用同一称呼、学号和密码重新登录后，首页会显示“管理后台”，也可以直接访问 `/admin`。

管理页可以按称呼或学号搜索账号，查看注册时间、最后登录时间和消息数量，并将最近最多 500 条消息按会话浏览；完整聊天正文可下载为 JSON。页面不提供删除用户、删除聊天或修改权限的操作。普通账号即使直接访问 `/admin`，也不能绕过后端权限校验。

## 紧急情况

如果你或身边的人有立即伤害自己或他人的风险，请立刻联系 `120`、`110`，或请可信任的人到身边陪伴。也可拨打全国统一心理援助热线 `12356`，并联系学校心理中心、辅导员或校医院。

本项目不能替代紧急服务、心理咨询或医疗诊断。校园资源文本应由部署者在每次正式使用前人工复核。
