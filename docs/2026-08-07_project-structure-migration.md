# 2026-08-07 Project Structure Migration

## Scope

The former `psynknight/` checkout was promoted to the `聆心小开/` workspace root. Application runtime paths inside `templates/` and `web/` were preserved so Flask and Vite continue to use the existing entrypoints.

## Path Map

| Before | After | Role |
| --- | --- | --- |
| `psynknight/templates/` | `templates/` | Flask backend, legacy pages, runtime assets |
| `psynknight/web/` | `web/` | Vue and Vite source |
| `psynknight/icon/1.png` | `assets/lion-avatar.png` | Maintained standalone image asset |
| `psynknight/templates/API_SECURITY_GUIDE.md` | `docs/security/API_SECURITY_GUIDE.md` | Security reference |
| `psynknight/templates/依赖问题解决方案.md` | `docs/operations/dependency-troubleshooting.md` | Operations reference |
| `psynknight/templates/dmxapi_chat.py` | `scripts/experiments/dmxapi_chat.py` | Standalone experiment |
| `psynknight/templates/gunicorn_conf.py` | `configs/gunicorn_conf.py` | Deployment configuration |
| outer `Prompt.txt` | `docs/reference/system-prompt.txt` | Prompt input |
| outer DOCX files | `docs/operations/` and `docs/user-guide/` | Project documents |
| outer `message.png` | `artifacts/evidence/message.png` | Evidence screenshot |

## Generated and Local-Only Areas

- `templates/dist/` is generated by `cd web; npm run build` and is kept for direct Flask startup.
- `web/node_modules/` and `templates/*_venv/` are local dependencies and are ignored.
- `templates/.env`, `templates/data/`, `templates/logs/`, `*.db`, and `*.log` remain local-only.
- `archive/2026-08-07-original-git/` preserves the previous repository metadata and is ignored by the new repository.

## Validation Entry Points

- Frontend typecheck and build: `cd web; npm run build`
- Backend entrypoint: `templates/server.py`
- Gunicorn config: `configs/gunicorn_conf.py`
- Health endpoint: `GET /api/health`
