# 项目交接清单与已知限制

## 接手时先确认

- 能访问代码仓库、部署主机、域名/反向代理配置和 DeepSeek 凭据管理平台。
- 知道正式 SQLite 文件和备份目录的实际位置、保留周期与访问负责人。
- 确认谁有管理员授权权、聊天数据导出权和密钥轮换权。
- 对照 `.env.example` 核对生产环境变量，但不要把真实值粘贴到文档或工单。
- 在隔离环境完成后端测试、前端构建和一次手工冒烟测试。

## 日常维护职责

- 依赖升级：查看官方发布和安全公告，小步升级，禁止 `npm audit fix --force`。
- 数据：发布前备份，定期验证备份可恢复；导出文件及时进入受控存储。
- 密钥：人员变更或疑似泄露时轮换 `SECRET_KEY` 与 DeepSeek 密钥。
- 内容安全：定期复核危机关键词、固定回复和学校联系方式。
- 文档：接口、配置、启动方式、目录或行为变化必须同步更新 `docs`。

## 发布验收

- [ ] `templates\.venv\Scripts\python.exe -m pytest -q` 全部通过。
- [ ] `npx.cmd tsc --noEmit` 和 `npm.cmd run build` 通过。
- [ ] `npm.cmd audit --audit-level=high` 无 high/critical。
- [ ] `git diff --check` 无空白错误。
- [ ] 仓库扫描无真实密钥、密码、测试账户、数据库、聊天日志或地理位置采集。
- [ ] 新用户注册、重复学号提示、登录、退出和刷新恢复正常。
- [ ] `/info`、`/companion` 聊天、SSE、历史恢复/删除和情绪分析正常。
- [ ] 危机表达直接返回固定内容，未触发 DeepSeek 请求。
- [ ] 普通用户无法访问用户列表、他人记录或管理员导出。
- [ ] 管理员能导出，导出文件按敏感数据处理。
- [ ] `<script>`、`<img onerror>` 等输入只显示为文本。
- [ ] 后端停止时页面明确提示服务不可达。

## 当前已知限制

- 只支持学生自助注册，没有学校统一身份认证、邮箱验证或忘记密码流程。
- 管理员通过服务器 CLI 管理，没有图形化权限后台。
- SQLite、单 Gunicorn worker 和进程内限流适合单机低并发，不支持直接横向扩容。
- 数据库迁移是应用启动时的有限向前迁移，没有独立版本表或自动回滚。
- 两个传统页面仍是大体量单文件 HTML，并依赖外部 CDN 的 Font Awesome、Three.js 和 ECharts；离线或 CDN 故障会影响部分视觉/图表功能。
- Vue 与传统页面并存，公共 UI 没有统一组件体系；本阶段只共享了请求模块。
- 情绪分析依赖通用模型输出，虽做了六维归一化，但不是经过临床验证的量表。
- 危机检测是显式关键词规则，无法覆盖隐晦表达；固定回复也不能替代人工值守。
- `/api/health` 只检查 Flask 响应，不检查 DeepSeek 或数据库读写深度。
- `templates/dist` 提交到仓库以便直接部署，因此每次 Vue 修改都会产生新的哈希文件变更。

## 不应恢复的旧实现

- 任意注册管理员或按姓名/学号推断管理员。
- Bearer Token/localStorage 认证兼容层。
- 通用 AI 代理、Hiagent、TTS、卡片生成或客户端 system prompt。
- JSONL 聊天双写、聊天正文日志和浏览器地理位置采集。
- 未清洗的 Markdown `innerHTML` 渲染、伪登录页或失效用户/设置页面。

如需要突破以上限制，应单独立项并先补测试，不在紧急修补中扩大架构。
