# AI 行为边界

## 模型与上下文

Node `agent-service` 在组合层解析 `deepseek-v4-flash`，使用 Pi 的 `Agent` 与 OpenAI-compatible 流式适配器。Flask 业务层只知道本机网关，不感知 Provider。

普通陪伴/科普聊天关闭思考模式。每轮上下文为：心理支持摘要、最近约 20k token 原文、最新状态快照和当前输入。默认保留 `reserveTokens=16384`；完整历史仍由 Flask 保存。

摘要只应保留明确事实、持续困扰、已尝试方式、保护因素、未完成话题和带时间语境的安全陈述；不能捏造诊断、用户事实或当前风险。

## 陪伴对话节奏

`companion` 使用由会话中用户轮次和当前输入推导的对话阶段，而不是将固定长提示词直接套到每一轮：前两轮优先探索感受与情境，第 3–5 轮澄清触发、影响或既有应对，之后才反馈用户已经表达的模式。每轮以简短的共情反映和一个自然问题推进；不主动给出长篇方法或列表。只有用户明确询问“怎么做 / 怎么办 / 给建议”等时，才进入“小行动”阶段，提供一个可选尝试并继续确认是否适合。

该阶段控制仅改变普通陪伴回复的引导方式；它不保存为用户画像，不改变 Pi 的 Provider 抽象、上下文压缩、工具权限或风险预检与危机绕过。

## 工具

仅允许：

1. `lookup_psychoeducation(topic)`：本地审核心理科普卡。
2. `get_support_resources(region)`：固定支持资源。

没有 Shell、文件系统、数据库、网络搜索或任意 HTTP 工具；一轮至多两批工具调用。

## 风险处理

1. 确定性规则先识别明确自伤/自杀表达。
2. 未达到高风险时执行短结构化高推理预检；模型结果只能提高，不得降低规则等级。
3. 预检解析或 Provider 失败时，继续以规则结果为最低安全底线。
4. `high` 与 `imminent` 直接返回固定的 12356、110、120 与校园支持信息，跳过普通 Agent 和工具。

系统不会自动通知学校、家长、警方或任何第三方。危机文本应由人类立即介入；该实验功能不是危机干预替代品。

## 状态回顾

陪伴模式完成且无高风险时，系统可保存“情绪、关切、日常功能、保护因素、信息充分度、后续关注目标”六项。状态回顾接口先按当前会话已保存的用户表达计算准备进度，少于 8 次只返回 `collecting` 和剩余次数，不公开早期 `unknown` 字段；达到 8 次后才返回最新快照。信息不足的单个字段仍保留原始 `unknown` 或 `insufficient` 值，前端分别显示为“暂无明确提及”和“信息仍有限”。8 次门槛只是展示准备度，不是量表信效度、诊断有效性或风险判断。这些字段不应被展示为分数、比例、诊断或风险灯。
